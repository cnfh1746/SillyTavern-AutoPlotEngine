## 功能特点

### 核心功能
- 🤖 **AI驱动的剧情生成**: 使用外部AI（OpenAI兼容API）自动生成剧情大纲
- 👤 **角色信息提取**: 从对话中提取角色信息并创建世界书条目
- 📖 **角色日志系统**: 自动记录角色经历的重要事件
- 🎭 **智能多角色识别**: 自动识别群聊中的所有角色并批量生成日志
- 🤖 **AI指令模式**: 使用自然语言指令批量处理角色日志

### 技术特性
- 📚 **世界书集成**: 自动将内容写入角色卡的主世界书
- ⚙️ **高度可配置**: 支持自定义API、模型、提示词等
- 📊 **详细日志**: 完整的日志系统，方便调试和监控
- 🎯 **智能触发**: 基于消息数量自动触发生成
- 🔕 **静默模式**: 支持后台无打扰运行

---

## 安装方法

1. 将 `SillyTavern-AutoPlotEngine` 文件夹复制到 SillyTavern 的扩展目录：
   ```
   SillyTavern/public/scripts/extensions/third-party/
   ```

2. 重启 SillyTavern 或刷新页面

3. 在扩展管理中启用"AI组手"

## 功能详解

### 1. 剧情大纲生成

#### 功能说明
自动分析对话历史、角色设定和世界观，生成富有戏剧性的后续剧情大纲。

#### 使用方法

**自动模式（推荐）**
1. 设置"运行模式"为"自动"
2. 配置"自动触发阈值"（如：每10条消息触发一次）
3. 正常对话，系统会自动生成剧情大纲

**手动模式**
1. 设置"运行模式"为"手动"
2. 需要时点击"立即生成剧情大纲"按钮

#### 世界书条目配置
- **条目名称**: "宏观剧情"
- **触发关键词**: 剧情、plot、大纲、故事、情节
- **插入位置**: @ Depth（可配置）
- **插入深度**: 1（可配置）

---

### 2. 角色信息提取器

#### 功能说明
从当前对话中分析并提取指定角色的详细信息，自动创建格式化的世界书条目。

#### 使用步骤
1. 切换到"角色功能"标签页
2. 输入要提取信息的角色名称
3. 点击"提取角色信息"按钮
4. AI会分析上下文并生成该角色的详细信息条目

---

### 3. 角色日志系统 ⭐

#### 功能概述
自动记录角色在对话中经历的重要事件，追加到世界书条目，形成持续增长的历史时间线。

#### 主要特点
- ✅ 智能事件提取
- ✅ 自动追加到现有条目
- ✅ 时间线格式（YYYYMMDD + 描述）
- ✅ 第一人称视角
- ✅ 可自定义提示词

#### 使用模式

**模式一：手动生成**

*基础用法 - 单角色*
```
1. 输入角色名称（如：小明）
2. 点击"立即生成日志"
```

*高级用法 - AI指令模式* ⭐
```
1. 输入自然语言指令：
   "请读取对话中的表格，为所有角色生成日志"
   "分析最近的对话，为所有参与的角色生成日志"
   
2. 系统自动检测并切换到AI指令模式
3. AI分析对话并批量处理
```

**模式二：自动生成**

*单角色模式*
- 指定目标角色
- 设置触发阈值
- 系统自动生成

*智能多角色模式* ⭐
- 启用"智能多角色识别"
- 自动识别所有AI角色
- 批量生成日志
- 适合群聊场景

#### 配置选项

**基本设置**
- 启用角色日志
- 运行模式（自动/手动）
- 自动触发阈值（5-50条消息）
- 目标角色

**高级设置**
- 智能多角色识别
- 分析消息数量（默认1条AI消息）
- 存储模式（追加/独立）

#### 日志格式示例
```
历史事件：
20250607 {{user}}送了我一个项链作为生日礼物
20250608 我和{{user}}确立了恋爱关系
20250609 第一次和{{user}}发生了亲密关系
```

#### 使用场景

**场景1：单人RP**
```
- 运行模式：自动
- 智能多角色识别：关闭
- 自动触发阈值：15条
```

**场景2：群聊**
```
- 运行模式：自动
- 智能多角色识别：启用
- 自动触发阈值：30条
- 静默模式：启用
```

**场景3：表格批量处理**
```
使用AI指令：
"请读取对话中的表格，为所有角色生成日志"
```

#### 最佳实践

**避免识别历史角色：**
- 分析消息数量 = 1
- 自动触发阈值 = 1

**节约API：**
- 使用手动模式
- 提高触发阈值
- 禁用不需要的功能

## 配置说明

### API配置
- **API URL**: OpenAI兼容的API地址
- **API Key**: 你的API密钥
- **模型**: AI模型名称
- **温度**: 控制随机性（0-2）
- **最大Token数**: 生成内容长度

### 剧情大纲配置
- **启用剧情大纲**: 总开关
- **运行模式**: 自动/手动
- **触发阈值**: 消息数量
- **剧情生成提示词**: 自定义提示词
- **世界书条目配置**: 关键词、位置、深度

### 角色日志配置
- **启用角色日志**: 总开关
- **运行模式**: 自动/手动
- **触发阈值**: 消息数量
- **目标角色**: 指定角色名
- **智能多角色识别**: 自动识别所有角色
- **分析消息数量**: 只分析最近N条AI消息
- **存储模式**: 追加/独立
- **日志生成提示词**: 自定义提示词

### 核心设置
- **静默模式**: 关闭所有弹窗通知

## 故障排除

### 世界书条目未出现
1. 确认角色卡已绑定主世界书
2. 检查浏览器控制台是否有错误
3. 查看扩展日志了解详细信息
4. 尝试手动刷新世界书UI

### API调用失败
1. 检查API URL格式是否正确
2. 确认API Key有效
3. 验证网络连接
4. 查看API服务器日志

### 角色日志生成失败
1. 确认角色世界书条目已存在（可用角色提取器创建）
2. 检查API配置
3. 查看运行日志中的详细错误
4. 尝试切换存储模式

### 未检测到角色（智能多角色模式）
1. 增加"分析消息数量"
2. 确认最近对话中该角色有发言
3. 检查角色名称格式
4. 尝试使用手动模式

### AI指令模式未触发
1. 确保输入长度超过20字符
2. 包含触发关键词（请、分析、表格等）
3. 查看日志确认模式切换

## 技术支持

扩展提供了详细的日志系统，可以在设置面板的"运行日志"标签页查看：
