# SillyTavern 自动剧情引擎

自动分析世界状态并生成剧情大纲的 SillyTavern 扩展。

## 功能特点

- 🤖 **AI驱动**: 使用外部AI（OpenAI兼容API）自动生成剧情大纲
- 📚 **世界书集成**: 自动将剧情大纲写入角色卡的主世界书
- ⚙️ **高度可配置**: 支持自定义API、模型、提示词等
- 📊 **详细日志**: 完整的日志系统，方便调试和监控
- 🎯 **智能触发**: 基于消息数量自动触发剧情生成

## 安装方法

1. 将 `SillyTavern-AutoPlotEngine` 文件夹复制到 SillyTavern 的扩展目录：
   ```
   SillyTavern/public/scripts/extensions/third-party/
   ```

2. 重启 SillyTavern 或刷新页面

3. 在扩展管理中启用"自动剧情引擎"

## 使用前提

⚠️ **重要**: 使用本扩展前，必须为当前角色卡绑定一个主世界书。

在角色卡设置中，找到"世界书"部分，选择或创建一个世界书作为主世界书。

## 配置说明

### API设置
- **API URL**: OpenAI兼容的API地址（如 `http://127.0.0.1:8888/v1`）
- **API Key**: 你的API密钥
- **模型**: 选择要使用的AI模型

### 生成设置
- **触发阈值**: 每隔多少条消息自动生成一次剧情大纲
- **温度**: 控制生成的随机性（0-2）
- **最大Token数**: 生成内容的最大长度

### 提示词设置
可以自定义系统提示词和用户提示词模板，控制AI如何生成剧情大纲。

## 世界书条目设置

生成的剧情大纲会以以下设置写入世界书：

- **触发关键词**: 剧情、plot、大纲、故事、情节
- **扫描深度**: 1（仅扫描最新消息）
- **常驻模式**: 是（始终激活）
- **位置**: before_char（在角色定义之前）
- **优先级**: 100

## 手动触发

除了自动触发外，也可以在扩展设置面板中点击"立即生成剧情"按钮手动生成。

## 日志查看

扩展提供了详细的日志系统，可以在设置面板的日志区域查看：

- **INFO**: 一般信息
- **SUCCESS**: 操作成功
- **WARN**: 警告信息
- **ERROR**: 错误信息
- **DEBUG**: 调试信息（需要启用调试模式）

## 故障排除

### 世界书条目未出现

1. 确认角色卡已绑定主世界书
2. 检查浏览器控制台是否有错误
3. 查看扩展日志了解详细信息
4. 尝试手动刷新世界书UI

### API调用失败

1. 检查API URL格式是否正确
2. 确认API Key有效
3. 验证网络连接
4. 查看API服务器日志

### 扩展无法加载

1. 确认文件夹名称为纯英文（不含中文）
2. 检查文件完整性
3. 查看浏览器控制台错误信息
